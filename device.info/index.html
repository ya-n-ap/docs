    Preparatory Work

    Use a Proper Device

    If you're reading this guide on a mobile device, it's better to switch to a laptop or desktop. Some of the upcoming steps may not be supported on mobile platforms.

    A Reminder

    In the next steps you may or may not see the warning similar to one of the cases below. If you do, don't worry. It’s completely normal in this context. It happens because all YANAP services run within your local network, and therefore cannot obtain HTTPS certificates valid for the public internet.

    But if you see a similar warning elsewhere, you should be cautious, it could be very dangerous. Always make sure it’s safe before proceeding.

    Click the button in the lower-left corner labeled "Continue to site".

    Setp 1 - Click the button in the lower-left corner labeled "Advanced".

    Setp 2 - Click the link on the last line that says "Procced to .......... (unsafe)".


    Keep Device Info Page Ready

    Enter the URL below in your web browser to open your Device Info Page.

    • http://yanap.local

    You should see a page showing the following information. Keep it open. You’ll need this information in the next steps.

    • Your DNS Server Address
    • Your Router’s Web Interface
    • Your AdGuard Home Web Interface

    Note

    • If this page isn't ready or you see "___.___.___.___" (blank, without number) on it, it means the initialization tasks are still running. Please wait a few seconds.
    • The initialization should not take longer than 10 minutes. If you have waited more than 10 minutes, please restart the device and try again.


    Troubleshooting

    If you're unable to open http://yanap.local, try using a different web browser or operating system. Some systems or browsers do not support the .local domain.

    • Windows 10, Windows 11 support the .local domain by default.
    • Versions prior to Windows 10 do not support the .local domain by default.
    • macOS versions since macOS X Jaguar (version 10.2, 2002) support the .local domain by default.
    • All versions of iOS support the .local domain at the system level, though actual support may vary by app.
    • Android does not support the .local domain out of the box.

    • Most Linux distributions support .local domain, but functionality depends on your specific network configuration.

      Tip

      If you need help enabling support for the .local domain on your Linux distribution, try searching for "mDns configuration for Linux."
